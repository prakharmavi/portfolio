I studied computer programming at Seneca and now build web and mobile apps in Toronto.

I care about speed because users notice a 1.5-second delay. I start with the smallest version that works, then improve the data model, error handling, and logs after real use shows me where the weak spots are.

## What I work with

- Next.js, React, TypeScript, Node, and Postgres for web products
- Swift and React Native for mobile apps
- Redis or Valkey, background jobs, and queues when a product needs them

I prefer plain tools and small systems. They are easier to ship, debug, and change. I collect only the data the product needs.
