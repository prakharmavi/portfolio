I studied computer programming at Seneca. Now I build web and mobile apps in Toronto.

I care about the half-second most people wave off. If a screen drags, I want to know why.

I start small and ship the useful part. Once people use it, I fix the weak spots instead of guessing at them. I would rather run a boring tool I understand than babysit a clever setup.

I collect only the data the product needs. Everything else is noise.
